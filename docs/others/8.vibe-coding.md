## opencode 编码 agent

[opencode 在线文档](https://opencode.ai/docs/zh-cn/)

- 开源/免费的 AI 代码编写助手
- 提供免费的模型 API 非常适合学习
- 有 TUI/GUI 客户端

## skills 管理工具

[skills](https://www.npmjs.com/package/skills)

```sh
# skills 命令帮助
skills --help

# 添加 skills 到项目 gtihub-username/github-repo-name
skills add antfu/skills --skill='*' -g
skills add nextlevelbuilder/ui-ux-pro-max-skill --skills="*" -g

# 查看现有的 skills
skills list
```

## pi agent

pi 是一个用于定制编码 agent 的工具底座, 如果想要开箱即用推荐使用 codex/opencode 等工具

建议先阅读: [kickstart.pi](https://github.com/orionpax1997/kickstart.pi)

- [官方文档](https://pi.dev)
- [中文文档](https://pi-doc.com)
- [pi-web](https://github.com/agegr/pi-web) 类似 deepseek harness 的 webUI 远程控制项目


## deepseek harness

deepseek 开源的 harness, 与 codex/opencode 等不同的是, 你可以自由组装他的功能, 类似 pi

- [dsh-plugin-hub](https://github.com/dshplugin/dsh-plugin-hub) 社区插件市场
- [dsh-cloud-sync](https://github.com/dickpy/dsh-cloud-sync) 插件同步到 webdav/s3 服务器
- [dsh-plugin-session-delete](https://github.com/lsz-asd/dsh-plugin-session-delete) 删除一些已经做完/无用的会话
- [dsh-model-router](https://github.com/welsione/dsh-model-router) 模型自动回退:适合多个提供商
- [dsh-at-file](https://github.com/omdsh-dev/dsh-at-file) 使用@选择文件
- [DSH-better-sidebar](https://github.com/omdsh-dev/DSH-better-sidebar) 文件目录/任务管理侧边栏
- [dsh-complete-notify](https://github.com/kaixinbaba/dsh-complete-notify) 任务完成/需要选择播放语音通知
- [dsh-cost-meter](https://github.com/Han-1413141/dsh-cost-meter) deepseek余额/峰谷计价提示
